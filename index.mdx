# Personal Software Engineering Playbook

A permanent, educational, technology-agnostic engineering framework with specialized extensions for modern software development.

<Note>
This documentation site serves as the interactive reference manual for human software engineers and AI coding agents (Google Antigravity, Cursor, Claude Code, GitHub Copilot).
</Note>

## ⚡ 30-Second Quick Start

Starting a new project? Follow these 3 simple steps:

<Steps>
  <Step title="Copy Universal Agent Governance">
    Copy `AGENTS.md` into the root of your new project repository to establish non-negotiable engineering safety, inspection gates, and verification rules.
  </Step>
  <Step title="Follow the 8-Stage Bootstrap Workflow">
    Follow the [Project Bootstrap Workflow](/docs/guides/PROJECT_BOOTSTRAP_WORKFLOW) from discovery and project classification to CI setup and production release.
  </Step>
  <Step title="Select Your Project Templates">
    Choose from the [Templates Catalog](/templates/01-PROJECT_BRIEF_TEMPLATE) to copy production-ready templates for your Project Brief, Architecture Design, and Test Plans.
  </Step>
</Steps>

## 🏛️ Layering Architecture: The 3-Tier Model

* **Tier 1 (Universal Core)**: Timeless engineering principles, 12-stage SDLC, universal architecture patterns, security hygiene, and quality standards.
* **Tier 2 (Technology Extensions)**: Deep idioms for Android (Compose/Kotlin), Web (TypeScript/React), Backend (REST/APIs), and Database (PostgreSQL).
* **Tier 3 (Project Overlays)**: Project-specific configurations, domain business logic, and progress tracking in target application repositories.
